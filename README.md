# dsh-session-delete

> 在 DSH 侧边栏对话菜单中**真正永久删除**会话，以及工作区级别的批量归档/删除 —— 从文件系统层面删除会话日志，而不是像归档那样仅仅隐藏。

DSH 官方客户端目前只提供「归档会话」（把会话从列表隐藏，日志文件仍留在磁盘）。本插件提供：

- **会话菜单**：「删除对话」入口 —— 永久删除单个会话的日志文件，**不可恢复**。
- **工作区菜单**：「归档全部会话」「删除全部会话」—— 批量操作整个工作区的会话。

> **v0.2.0** 适配 DSH ≥ 0.2.0-rc.2 的菜单 DOM 变更（`data-menu-material` 替代 `role="menu"`，`data-row-key` 行标识）。

## 功能特性

- ✅ **真实物理删除**：通过 shell 沙箱安全删除会话目录，非隐藏、非标记删除
- ✅ **运行中的会话保护**：活跃（打开/运行中）会话拒绝删除并提示，防止误删
- ✅ **记账同步清理**：`workspace.json` 的会话席位与全局归档集合一并清除
- ✅ **工作区批量操作**：一键归档/删除某个工作区下的所有会话
- ✅ **二次确认**：自定义确认弹窗，显示标题并明确提示不可恢复
- ✅ **行识别准确**：通过官方 `data-row-key="session:<id>"` 属性定位会话，杜绝误删
- ✅ **零依赖**：仅使用 Node 内置模块与注入的官方服务，无第三方运行时依赖

## 使用场景

- 清理不再需要的实验性对话、临时会话，释放磁盘空间
- 删除包含敏感内容的会话，确保日志从磁盘彻底消失
- 迁移工作区时一键归档/清理旧会话
- 归档无法满足的"彻底删除"需求（归档只是隐藏，文件仍可被搜索/导出找回）

## 安装

```sh
npx -p @deepseek-ai/dsh dsh plugin --profile web add github:RightFS/dsh-session-delete
```

安装完成后**重启 dsh web** 生效。

## 使用

### 删除单个会话

1. 在左侧对话列表找到目标会话，将鼠标移到该行，点击行尾的 `···` 按钮；
2. 菜单中点击「**删除会话**」（英文界面为 `Delete Session`）；
3. 在确认弹窗中点击确认；
4. 会话行立即从列表消失，磁盘上的会话日志已永久删除。

### 批量操作工作区

1. 鼠标移到工作区标题行，点击行尾的 `···` 按钮；
2. 点击「**归档全部会话**」或「**删除全部会话**」（英文为 `Archive All Sessions` / `Delete All Sessions`）；
3. 确认后执行。

> 删除**正在运行**的会话时，该会话将被跳过并提示。

## 工作原理

- **Host 半端**（`lib/index.js`）：注册三条本地路由 `POST /dsh-session-delete/{delete,delete-all,archive-all}`。
  - 活跃会话保护：通过 `sessions` 服务检测，拒绝删除正在运行的会话；
  - 沙箱删除：通过 `shell` 沙箱（`workspace-write` 模式）安全删除会话目录；
  - 记账清理：通过 `workspaceRegistry` 清理会话席位与归档集合。
- **Client 半端**（`lib/client.js`）：监听 portal 菜单表面（`div[data-menu-material="translucent"]`），克隆现有菜单项注入新条目；通过 `data-row-key` 属性识别点击的行；显示自定义确认弹窗。

## 安全与边界

- 删除在 shell 沙箱中执行（`workspace-write`，限定会话所属项目目录）；
- `sessionId` 严格校验，杜绝路径穿越；
- 附件（图片等）是跨会话共享资源，**不随会话删除**；
- 活跃会话拒绝删除，防止误删；
- 会话子代理（`subagents/`）各自独立存储，如需一并删除请逐个操作。

## 已知限制

- 批量删除工作区时不支持"取消选择某些会话"的精细控制；
- 菜单注入依赖官方客户端的 DOM 结构，DSH 升级可能需同步适配。

## 常见问题

| 问题 | 说明 |
| --- | --- |
| 点击后菜单中没有出现删除选项 | 插件可能未正确安装，请重启 DSH 后重试（控制台 `[dsh-session-delete]` 日志可确认加载状态） |
| 提示"该会话正在运行" | 该会话当前打开或在处理中，请切换到其他会话或等回复完成后再删 |
| 删除后磁盘占用没有减少 | 附件为跨会话共享资源，不会被删除；仅会话日志目录被移除 |
